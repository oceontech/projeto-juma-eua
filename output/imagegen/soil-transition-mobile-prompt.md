# Mobile soil background

Tool: built-in image_gen, desktop soil image used as material/color reference.

Generated PNG: `web/public/img/kmep/soil-transition-mobile.png`.
Web export: `web/public/img/kmep/soil-transition-mobile.webp` (quality 90, alpha preserved).
Applied below 768px by `TwoJobs.module.css`, shared by /kmep and /kmep-b.

Prompt:

Use case: photorealistic-natural. Create the MOBILE PORTRAIT companion asset to the provided desktop soil background, using that image as material/color reference. Output one vertical PNG with real alpha transparency, requested size 1024 x 2048, aspect ratio 1:2.
This is a usable background for a narrow phone webpage, with cream colored text overlaid in HTML later. Photograph-like frontal cutaway of rich dark brown agricultural earth spanning edge to edge. The ground surface is a gently uneven shallow contour at 3% to 5% of image height, with small loose clods and fine grains. All empty space ABOVE that irregular silhouette is actually transparent (alpha zero), not black. Below the silhouette is one continuous opaque soil cross section down the whole image. Use SMALL fine-scale soil aggregates, realistic fine mineral specks, sparse very fine short roots, detailed but calm organic texture. Match the reference earthy materials but compose this specifically vertically; do not just crop or enlarge the reference. No huge clods, no large roots, no rocks as focal points. Soil details must read finely at phone width. Soft low-key lighting, muted dark brown. Start darkening below 35% image height, smoothly reduce contrast and texture through the lower half and fade gradually to exactly flat solid charcoal #0C0C0E (RGB 12,12,14). Entire bottom 15% must be completely uniform opaque #0C0C0E. Keep the top soil edge distinct. No plants, grass, sky, landscape, horizon scenery, text, logo, UI, border, checkerboard pattern or watermark. Actual alpha above the surface ONLY; soil and bottom are opaque.
